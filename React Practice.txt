Component Requirements
Create the following components:

Home.js – Functional component that displays the message: "Home Page"

AboutUs.js – Functional component that displays the message: "About Us"

ContactUs.js – Class component that displays contact details

Counter.js – Functional component with a counter feature

 Routing Setup
Use React Router to set up navigation between the components.

Display the appropriate component based on the selected route.

The Home Page should be the default route.

Add an additional route for Counter.js.

 Counter Component Functionality
In Counter.js:

Use the useState hook to manage the counter state.

Include two buttons:

Increment – increases the counter value

Decrement – decreases the counter value
